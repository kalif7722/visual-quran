# Automatic Tamil slide viewing
Select தமிழ் in the header, or use `?lang=ta` on a Surah URL. Language preference persists locally. The viewer fetches `/api/surah-slides/{id}/{slug}/{en|ta}`; the Worker lists only the corresponding R2 `surahs/{id}-{slug}/{language}/` prefix, paginates, filters canonical WebP filenames and sorts numerically. The actual uploaded files determine count and filenames; a language manifest is optional for display. No build or shared-manifest edit is needed after further uploads. Refresh uploads repeats discovery; API results are not cached. Missing languages show a truthful empty state instead of English slides. Existing slide metadata labels are only used for English; Tamil slides have their own actual count and generic slide labels.

Example: `surahs/001-al-fatihah/ta/001-al-fatihah-01.webp` and optional `surahs/001-al-fatihah/ta/manifest.json`. Keep English files in `/en/`. The Worker uses its existing R2 binding; browser asset URLs use the configured asset base or `/media` fallback.
